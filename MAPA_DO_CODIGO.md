**Como localizar:** clique no link relativo para abrir o arquivo. O texto depois de `→` é o termo literal para buscar com `Ctrl+F`. Quando o recurso é implementado em um arquivo e usado em outro, ambos aparecem na célula. `src/` é relativo à raiz do projeto, a mesma pasta deste mapa.

**Antes do ensaio:** configure o token conforme o [README.md](README.md). Uma sugestão de busca é **Interestelar**, mas não houve credencial disponível para verificar esse filme na API nesta entrega. Os filmes de nome “teste” pertencem exclusivamente aos testes automatizados e não aparecem no app normal.
